Backend Integration Architecture

This frontend is completely modular, framework-free, and has zero build-time steps. All HTTP queries route through js/api.js:

  • Flask Integration: Set static_folder='frontend' in your Flask application.
  • FastAPI Integration: Mount with StaticFiles(directory="frontend", html=True).
  • Production Deployment: Flip USE_MOCK = false in js/config.js.
